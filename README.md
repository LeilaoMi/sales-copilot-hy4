## 1. 为什么是它

销售工具的通病是：**记起来太麻烦，所以用两天就废了。**

传统 CRM 填十几个字段才存得进一条跟进，结果就是晚上补记、凭印象填、数据全是假的。
本工具只围绕一件事：**让你在客户楼下等电梯的 30 秒里，把刚发生的事记完。**

| 对比项 | 常见 CRM | 销冠助手 |
|---|---|---|
| 记一条跟进 | 打开表单 → 选客户 → 选类型 → 填内容 → 提交 | 一句话，回车，确认即存 |
| 安装 | 公司服务器 / SaaS 账号 | 一个 HTML 文件，或一个网址 |
| 断网 | 用不了 | 照常用，联网后自动补同步 |
| 数据归属 | 厂商的库 | 你浏览器的 localStorage |
| 成本 | 按人头按月 | 0 |

**三条定位：**

1. 先是一个人的本地工具，后才是团队工具，没登录也能完整用。
2. 规则优先，AI 兜底，电梯口地铁里没网也能记。
3. 先出结果再确认入库，脏数据比不记更糟。

## 2. 功能总览

共 9 个模块，底部页签切换。`团队`只对管理员显示。

| 模块 | 一句话 | 关键点 |
|---|---|---|
| 战情台 | 打开即作战面板 | 本月回款 / 目标完成率 / 今日待联系 / 风险商机 / 近 7 天跟进 |
| 客户库 | 分级管理 + 详情时间线 | A 重点 / B 常规 / C 观察；详情含跟进线、关联商机、此刻该说什么 |
| 商机看板 | 七阶段拖拽推进 | 线索 10% / 接触 25% / 方案 45% / 报价 65% / 谈判 80% / 赢单 100%，输单不在板上 |
| 跟进日志 | 全部跟进倒序 | 按客户、电话 / 微信 / 拜访 / 会议 / 邮件筛选 |
| 话术库 | 48 条实战 + 语义搜索 | 9 大类，一键复制，赢输单可沉淀自己的话术 |
| 周报 | 自动归拢一周动作 | 新增客户、推进商机、跟进次数、下周待办，可复制发出 |
| AI 助手 | 可选增强 | 销售建议、话术生成、周报润色、输单复盘，需配 Key |
| 团队看板 | 只管理员可见 | 全队在谈金额 / 商机数 / 赢单数，不显示客户具体名字 |
| 设置 | 个人 + 系统配置 | 目标、提成、AI、同步、导入导出、健康度灵敏度 |

## 3. 快速开始

### 方式一：单文件版（推荐先试两天）

```bash
node tools/build.js
```

生成 `销冠助手-单文件版.html`（约 470KB），双击即用，可丢网盘发微信存手机。
构建产物不进仓库，只需 Node，无任何 npm 依赖。

### 方式二：本地跑源码

```bash
git clone https://github.com/LeilaoMi/sales-copilot-hy4.git
cd sales-copilot-hy4
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

任何静态服务器都行。不能直接双击 `index.html`，浏览器不允许 `file://` 加载多文件 JS。

### 方式三：自带同步后端跑

```bash
node server/server.js
PORT=3000 node server/server.js
SYNC_TOKEN=你的长令牌 node server/server.js
```

一个文件同时提供静态站点 + `/api/sync` + `/api/health` + `/api/backups`，适合局域网自托管。

> 首次打开带示例数据（10 家客户、19 商机、13 跟进），设置里清空即可，不会再自动出现。

## 4. 核心功能详解

### 4.1 一句话录入

战情台顶部输入框，一句话回车自动拆字段，确认即存。原文保留不动。

```
今天去了王总那儿，聊了报价，他说下周三再联系
```

| 字段 | 结果 | 说明 |
|---|---|---|
| 客户 | 恒力精工制造（王建国） | `王总`按姓加职务命中 |
| 类型 | 拜访 | `去了`命中拜访 |
| 下次跟进 | 下周三 | 意图词`再联系`附近的时间 |

匹配三轮：全名最长命中 → 简称 4 到 2 字（多人判歧义）→ 姓加职务（王总 / 陈经理 / 马主任，复姓单处理，同姓用公司简称消歧）。

时间听懂今天 / 明天 / 后天 / 大后天 / 下周三 / 3 天后 / 2 周后 / 9 月 5 日等，周一为周首。

> 克制：只有`下次 / 回头 / 再联系 / 跟进 / 改天`等词才设下次跟进。`他说下周三报价`是对方时间不等你要联系，宁可不设。句首`今天去了`是行动时间，不误取今天。

### 4.2 商机健康度

在谈商机 0-100 分，四信号扣分并给一句话动作。

| 信号 | 最多扣 | 判定 |
|---|---|---|
| 沉默 | 35 | 对比你自己的跟进节奏 |
| 阶段停滞 | 30 | 对比你走完该阶段的历史耗时 |
| 临期过期 | 35 | 预计成交日剩几天或已过几天 |
| 无实质推进 | 10 | 近 30 天没换阶段没记跟进 |

基准自学习：跟进节奏超 1.6 倍算异常，阶段耗时取中位数需 3 样本，否则用 A/B/C 兜底并明说估算。新建 3 天不评，可忽略 7 天，灵敏度 0.4-2.5 可调。

### 4.3 回款预测与目标倒推

```
保守 = 金额 × 本月内成交概率 × 阶段赢率，逐单累加
乐观 = 金额 × 本月内成交概率，逐单累加
```

赢率优先用你自己的历史算出，样本不够用默认档。没填成交日按最低估并提醒补。倒推给还差多少、差几单、来不来得及。

### 4.4 话术库（48 条，9 大类）

| 分类 | 条数 |
|---|---|
| 异议处理 | 16 |
| 催单推进 | 6 |
| 开场破冰 | 5 |
| 需求挖掘 | 5 |
| 售后维护 | 5 |
| 谈判博弈 | 4 |
| 方案报价 | 3 |
| 复盘沉淀 | 2 |
| 交付履约 | 2 |

语义加意图标签搜索，`嫌贵`能命中标题无贵字的话术。赢输单当下弹窗沉淀自己的话术。

### 4.5 AI 助手（32 家）

不配 Key 不影响其他功能。设置选服务商填 Key 保存测试，各家兼容 OpenAI 协议。

国内 12 家：DeepSeek、智谱 GLM、通义、硅基、Kimi、千帆、混元、阶跃、零一、MiniMax、豆包、星火（后两家浏览器直连被拦）。
海外 16 家、本机 3 家（Ollama / LM Studio / vLLM）、自定义 1 家。

5 家浏览器直连被拦：豆包、星火、Groq、Cerebras、SambaNova，下拉带标记，换 DeepSeek / 智谱 / 通义 / 硅基。地址填错自动试 6 种写法。

### 4.6 周报与陪练

周报本地算术归拢不漏单，可复制发老板。陪练每三轮点评，离线可背书。场景只挑`客户说` `对方`开头，故显示`48 条其中 23 个适合对练`正常，自建`客户说`自动进来。

### 4.7 多人与团队

| 角色 | 能看到 | 能做 |
|---|---|---|
| 管理员 | 自己全部 + 团队看板 | 发邀请码、移人、看进度 |
| 成员 | 仅自己 | 加入退出 |

隔离在 Postgres RLS 层。搭建：建 Supabase 项目 → SQL 执行 `db/supabase.sql` → 设置填 URL + anon key → 首个注册成拥有者 → 发邀请码。表：profiles records teams team_scripts user_settings。

### 4.8 云同步

本地优先，先写 localStorage。按 updatedAt 逐条 LWW，删除走墓碑。不配只本地，Supabase 长期多人，自建跑 `server/server.js`。Pages / Vercel 跑不了 Node，必须走 Supabase。

## 5. 部署到线上

> 只部署 `public/`，根里 `data/` 是真实客户资料，静态托管全文件可下载，整目录传等于挂名单。

```bash
node tools/build.js --pages
npx wrangler pages deploy public
npx vercel --prebuilt --prod
```

Pages 后台输出目录填 `public`，缓存源 `deploy/_headers`。手机添加主屏幕即 PWA 离线全屏。详见 `docs/DEPLOY.md`。

## 6. 数据与隐私

| 问题 | 答案 |
|---|---|
| 存哪 | 浏览器 localStorage |
| 作者服务器 | 没有，除非你自己配 |
| data/ | server 本地快照，已忽略永不进库 |
| 换浏览器清缓存 | 会没，开同步或定期导出 JSON / 数据码 |

构建有泄漏检查，public 里出现 data 或业务 JSON 直接报错。
